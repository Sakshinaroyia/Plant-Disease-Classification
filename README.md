Problem Statement

Farmers often face challenges in identifying plant diseases at an early stage, leading to:

- Reduced crop yields  
- Increased dependency on manual inspection  
- Need for expert intervention  

There is a **critical need** for a scalable, intelligent solution that can **automatically detect plant diseases** and assist farmers in timely action.

---

Our Solution

We developed an **AI-powered Plant Disease Detector** that:

- Uses **Convolutional Neural Networks (CNNs)** trained on **38 plant disease classes**
- Employs **image augmentation** for robust learning
- Leverages **transfer learning** with pre-trained models for better accuracy and efficiency
- Is **camera-friendly** and suitable for **mobile/web integration**
- Built using **Python, TensorFlow, Keras, and OpenCV**

How It Works

1. **Image Input**: User captures or uploads a leaf image  
2. **Preprocessing**: Image is resized, normalized, and augmented  
3. **Prediction**: CNN model classifies the image into one of 38 disease/healthy classes  
4. **Output**: Displays disease name and confidence score
